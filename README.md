# Data Science, Machine Learning & Cloud Engineering Portfolio

This portfolio showcases academic and independent projects spanning data science, machine learning, data engineering, cloud computing, and software development. Projects demonstrate practical experience with Python, SQL, predictive modeling, natural language processing, data transformation, automation, and cloud technologies.

---

## Projects

### ✅ Weather Forecast Program
- **Language:** Python
- **Description:** Object-oriented 7-day weather forecast application with statistical analysis and unit tests.
- **Folder:** `weather_forecast`

### ✅ Ambulance Dispatch System
- **Language:** Python
- **Description:** Dispatch simulation with Dijkstra and A* pathfinding prototypes and benchmark tools.
- **Folder:** `ambulance_dispatch`

### ✅ Unix/Linux Shell Automation
- **Language:** Bash
- **Description:** Collection of shell scripts automating administration tasks (users, packages, network, disk, archiving).
- **Folder:** `shell_automation`

### ✅ Hospital Staff Management Analytics
- **Language:** Python
- **Description:** ML pipeline processing 37k+ hospital records to predict high-risk facilities and generate staffing recommendations.
- **Folder:** `hospital_staff_analytics`

### ✅ Neural Network & NLP Research
- **Languages:** Python, Jupyter, shell
- **Description:** Projects including CIFAR‑10 spatial transformer networks, automated data cleaning pipelines, sentiment analysis of reviews, and spam classification.
- **Folders:** `network_evaluation`, `data_cleaning`, `sentiment_analysis`, `nlp_model/spam_classification`, `advanced_ai/machine_learning_research`

## Getting Started

To use any of the projects:

1. Navigate into the desired subdirectory (example):
   ```powershell
   cd weather_forecast
   ```

2. Each project has its own README with setup and execution instructions. Follow those to run the code or tests.

3. Ensure dependencies are installed (Python packages via `pip`, bash utilities on Unix, etc.).
