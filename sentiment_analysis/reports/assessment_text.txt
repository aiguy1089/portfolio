COMPETENCIES
4141.1.1 : Implements Natural Language Processing
The learner implements natural language processing techniques to analyze and process text data.   
INTRODUCTION
Understanding the role of data preprocessing in sentiment analysis is essential for effectively applying
natural language processing (NLP) techniques. In this task, you will complete a hands-on project in which you
prepare a dataset for sentiment analysis by selecting a data source, gathering and limiting the dataset to
fewer than 500 items, and applying appropriate NLP preprocessing techniques.
As part of this process, you will explore how different preprocessing methods—such as tokenization,
stopword removal, and text embedding—impact the accuracy and effectiveness of sentiment classiﬁcation
models. You will critically analyze the signiﬁcance of these techniques, reﬂecting on their role in improving
data quality and optimizing machine learning performance.
Additionally, this project can serve as a portfolio piece, showcasing your ability to preprocess real-world
textual data for sentiment analysis. A list of potential data sources is provided below, though you may choose
any appropriate dataset that aligns with the project requirements.
Note: The NLP techniques below are suggestions. The list is neither prescriptive nor exhaustive. 
•   tokenization
•   lowercasing
•   stopword removal
•   lemmatization
•   punctuation and special character removal
•   handling missing data
